# କବିତା ଲାଇଭ. — visual branding guide

Open `BRANDING-GUIDE.html` in a browser. It is a portable visual document: the illustrations and logo symbols are embedded. Google Fonts needs internet access; production should use licensed, self-hosted files. The browser’s Print / save as PDF action is available; a full-guide PDF is not included. A separate one-page editor’s cheat sheet is supplied as `editors-cheat-sheet.pdf` and `EDITORS-CHEAT-SHEET.html`.

The guide covers identity, the exact Odia name and final dot, both poetic signatures, logo variants, clear space, provisional minimum sizes, colours and contrast, typography for three scripts, imagery and motion, editorial applications, social-card compositions, voice and production handoff.

## Included assets

- `assets/logo-primary.svg`: editable full-colour wordmark and signature; transparent background.
- `assets/logo-ink.svg`: one-colour version.
- `assets/logo-reversed.svg`: paper-colour version for dark backgrounds.
- `assets/logo-compact.svg`: English logo without the signature.
- `assets/symbol-colour.svg`: full-colour symbol.
- `assets/symbol-ink.svg`: ink-only symbol.
- `assets/symbol-reversed.svg`: light symbol for a dark field.
- `assets/symbol-small.svg`: simplified small mark, without the tiny drop.
- `assets/brand-tokens.json`: exact names, signature, epigraph, colours and font choices.

Wordmark SVGs contain editable text. Install Source Serif 4, Noto Serif Oriya and the specified reading fonts for consistent rendering. They are review assets, not outlined or trademark-cleared production masters. Symbol SVGs contain self-contained paths. A lettering specialist should finish the wordmark and optical sizing before production.

The guide’s social cards are visual compositions using the existing title “ଦୋକାନ” and poet Narmada Nilotpala. They are not final 1200×630 or 1080×1080 exported images. Their source poem is https://kabitalive.com/poemview.php?id=809.

The Odisha-inspired watercolor was generated for the earlier approved design direction and is reused here. It is interpretive, not a claimed traditional artwork. The typography samples use the user-selected signature and epigraph plus generic Hindi labels; the English reading-layout sample is explicitly marked as sample copy.

## Review checks

The visual guide was checked in the browser on desktop and at a 320 CSS-pixel width: no document overflow or broken images. SVG files were parsed as XML; document anchors and supplied asset links were checked. Exact sRGB contrast values were recomputed and reconciled with the proposal. Print pagination, final-size print proofs, 16 px favicon tuning and a full accessibility audit remain production work.

Revision 05 adds the theme to every page, strengthens the English companion while keeping the Odia masthead primary, and uses realistic photographic cover studies. Each writer example has a searchable year-grouped contribution library sourced from the existing journal. The one-page A4 editor PDF was rendered and visually inspected; its Odia text uses the system Noto font for reliable shaping.
