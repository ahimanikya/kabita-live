Corrected findings

IV-AUD-01 · Corrected

Share dialog carried the historical logo

Found: The dynamically created share card used the old teal symbol asset.

Now: It now uses the current theme-aware mulberry leaf mark and aqua water drop, with the current SVG as fallback.

IV-AUD-02 · Corrected

Shared overlays retained blue-green shading

Found: Dialog and menu backdrops retained an old teal scrim; page-turn shadow also retained a teal tint.

Now: Backdrops use the charcoal Ink & Voice scrim; the fold shadow uses the existing theme shadow token.

IV-AUD-03 · Corrected

Search redirect fallback lacked the shared theme

Found: The redirect’s visible fallback did not load the complete design system.

Now: The fallback has the shared palette, fonts, spacing, saved/system theme and current favicon. Search still preserves the query when redirecting to Poems.

IV-AUD-04 · Corrected

English quotations inherited an editorial’s script font

Found: An English source quotation within a Hindi or Odia editorial inherited the surrounding script family.

Now: English quotation blocks explicitly use Literata, while Hindi and Odia quotations keep their own script families.

IV-AUD-05 · Corrected

Text enlargement broke the masthead and badge spacing

Found: At a 200% root text size, the masthead could split Kabita within the word and the Original badge could overlap a neighbouring language control.

Now: The masthead wraps at word boundaries; controls may add rows when necessary, and the Original target grows with enlarged text. Normal-size compact layouts are retained.

IV-AUD-06 · Corrected

Quiet-reader Original badge inherited the poem language

Found: The quiet reader’s English badge inherited the original Hindi/Odia script language and font.

Now: An explicit English language attribute keeps the small uppercase badge in the interface font; the source-language glyph retains its own script font.
