Editor Studio is its own shell

The private application intentionally keeps its approved light-only interface.

↳

Keep the reference current

Working source, rather than another frozen design mock-up.

Run python3 kb/artifacts/design/component-library/build.py after an approved component change. The builder refreshes source-derived specimens and records SHA-256 hashes in manifest.json.

Then run python3 kb/artifacts/design/component-library/check.py. This verifies provenance, safe fixtures, local assets and public-export exclusion. Browser review still checks appearance and interaction.

Shared styles load directly from the current workspace. A local specimen is not evidence that the same revision has been published. New component choices still require review.
