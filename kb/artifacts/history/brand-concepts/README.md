# Identity concept assets

These are original design studies for review, not approved production logos.

- `verse-mark.svg`: self-contained vector paths; script-neutral secondary symbol.
- `wordmark-study.svg`: font-dependent bilingual lettering study. Requires Anek Odia and Source Serif 4, with local fallbacks. The interactive preview loads these fonts; standalone SVG rendering may vary. Final production must refine Indic lettering, convert approved lettering to outlines and test small sizes.

The brand name and its Odia spelling need the publication editor’s confirmation. No trademark clearance is implied. The recommendation is to preserve Kabita Live as the existing publication name.

The design proposal specifies the full production asset set. These two files demonstrate the direction; they do not substitute for final master artwork and exports.
