# Implementation and preservation map

The primary design source remains `output/kabitalive-design-proposal-2026-09-29`. The portable copy remains `output/kabita-live-project`. `projects/site` points to the primary `site` directory through a relative symlink, so there is one implementation source.

Website preview: http://127.0.0.1:8771/ . Icon review: http://127.0.0.1:8771/icon-atelier.html . Research: http://127.0.0.1:8771/literary-study.html . Component review: http://127.0.0.1:8771/design-system-review.html .

Historical revisions, original artwork, font licences and existing ZIP snapshots remain preserved. Older ZIPs are revision-39 snapshots. The new icon candidate ZIP is separate and versioned. The portable folder includes updated site/guide files; its root contains a relocatable copy of the knowledge/configuration/tools, with paths adapted to the handoff layout.

The icon builder remains `output/kabitalive-design-proposal-2026-09-29/revision-40-literary-icons/build-study.py`; it produces the icon masters and public manifest. The KB icon list is a derived view of that manifest, regenerated by `tools/sync_design_knowledge.py`.

Run `python3 tools/registers.py`, `python3 tools/catalog.py`, and `python3 tools/check_bundle.py` after changing canonical KB records. `--check` on the first two detects stale generated views. The Blueprint checks do not publish the website.

Asset locations and counts are indexed by [artifact inventory](../records/artifact-inventory.json). Existing larger standalone delivery ZIPs remain historical snapshots rather than pretending to include the new Blueprint conversion.
