# Paper surface and reserved Pipili Chandua

The site now uses a lightweight, repeatable SVG grain texture over warm ivory. Fine grain at 5.5% opacity and broad fibres at 2.5% sit behind all content; text and artwork are not filtered. Texture is disabled in night reading, forced-colour mode and print.

Pipili Chandua is preserved unchanged in site/assets/art-library for future use, with its story and generation provenance in reserved-pipili-chandua.json. Issue 34 again uses Rain on the tiles and has a matching new narrative. The current collection still contains 47 covers and 47 stories.
