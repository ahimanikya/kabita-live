# A more inviting homepage

The new opening uses a large, realistic Odisha-inspired artwork alongside the Odia signature. The scene is titled “Life, after rain.” It imagines a rain-washed courtyard, an indigo doorway, a brass vessel, a white threshold drawing and green fields beyond. It is generated artwork, not a photograph of a named place or an existing magazine cover.

Desktop pairs a clear paper reading surface on the left with artwork on the right. Mobile places the image directly below the signature, followed by the translation, existing English epigraph and Read this issue action. The English masthead, 17 px navigation, poem previews and all inner-page artwork continue unchanged.

Original PNG and two optimized WebP sizes are saved under site/assets/home/. The page selects the smaller image for narrow screens and prioritizes the hero download. The prompt and generation method are documented in PROMPT.md.

Verification: homepage at 1280 and 320 CSS px passed automated axe A/AA checks with zero violations, broken images or overflow. Synthetic 200% text enlargement and expanded text spacing also fit without clipping or horizontal overflow. Desktop and narrow-screen layouts were visually inspected. These checks are not a complete accessibility certification; the existing magazine cover text overlays still require manual contrast review, as recorded by axe.
