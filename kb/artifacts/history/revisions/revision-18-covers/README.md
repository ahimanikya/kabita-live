# Forty-seven covers · Colours of home

A distinct portrait artwork for each verified edition, November 2022–September 2026. Built-in image generation was used, one prompt per asset. The originals are preserved as PNG; WebP copies serve the site, with smaller responsive versions for the archive. Self-contained SVG covers add an editable Kabita Live masthead, exact Odia signature, issue number and verified date.

## Palette

The user-provided Colours of home reference is the colour direction, not a copied identity. Digital values are an interpretation of that image:

- Ivory / reading surface: #F5EFDF
- Laterite / restrained emphasis: #963F28
- Sea blue / name and brand fields: #125465
- Hearth ochre / small earthy details: #78643A
- Reading ink: #263C3C
- Secondary copy: #655F51

The standalone SVG header ornament is a small leaf and two movements of water, drawn in the site’s existing vector language. Its transparent background and decorative semantics keep it quiet and accessible. It appears below the shared masthead across journal pages.

## Files

- site/assets/covers/editions/issue-NN.png: full-size generated master, without text.
- issue-NN.webp and issue-NN-480.webp: responsive website copies.
- issue-NN-cover.svg: self-contained cover with editable text; Source Serif 4 and Noto Serif Oriya are recommended for consistent shaping.
- site/assets/header-separator.svg: reusable separator.
- site/cover-catalogue.json: verified issue dates, source links, artwork titles and descriptions.
- manifest.json: exact prompts and generated-source provenance.
- creative-plan.json: all 47 distinct scene directions.

These are newly proposed covers for the redesign, not historical originals or descriptions of the poems in each issue. Generated settings evoke Odisha without claiming documentary locations. Historical content and source links are preserved. No changes have been published to the live website.

## Verification

All 47 artworks were visually reviewed in four groups. Representative editable covers and the one-page editor PDF were rendered and inspected. Each master is a unique 1024 × 1536 PNG. All local image and download links resolve. All 37 journal mastheads match after normalizing the active navigation attribute. Across 40 preview pages, desktop, 320 px mobile, 200% text and increased-spacing checks found no automated accessibility violations or horizontal page overflow. Lazy-loaded images are counted separately from failures. The archive year filter, list view and reset were checked against 2 / 2 / 47 visible editions. Automated checks are not a full WCAG certification.
