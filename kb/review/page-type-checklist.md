## Checks used for every page type

Review content hierarchy, unnecessary whitespace, imagery, typography, links, empty states, keyboard access and touch targets. Check the shared header, menu, theme persistence and footer on the page. Test representative narrow phones and desktop; expand checks when a problem appears.

For a template used by many pages, verify varied examples: short/long content, all supported scripts, missing imagery or content, and first/last navigation states where relevant. Do not treat one screenshot as proof that all variants pass.

Mockups are required for proposed design changes before application. If no changes are needed, record “not needed” with the review outcome. “Applied” may likewise mean the approved existing implementation was retained.
